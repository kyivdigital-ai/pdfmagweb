# Holographic Card

Static Vercel project for embedding in Readymag.

## Deploy
1. Upload this folder to Vercel or push to GitHub and import it.
2. No build command is required.
3. Deploy and copy the generated URL.

## Readymag
Use the deployed URL in an Embed / iframe block.

Recommended iframe:
<iframe
  src="https://YOUR-PROJECT.vercel.app"
  style="width:100%;height:100%;border:0;background:transparent;"
></iframe>

The background is transparent, the card has square corners, and it responds to mouse/touch.
